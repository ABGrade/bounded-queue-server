# Bounded Queue Server

Небольшой TCP-сервис очереди на C/POSIX threads, выросший из лабораторной работы Арсения Батуева по ОС. Производители добавляют символы, потребители извлекают их в порядке FIFO. Общая очередь защищена mutex.

Для самостоятельной демонстрации добавлены явные границы команд, обработка разделённых и объединённых TCP-пакетов, завершение соединений, ограничение числа клиентов и интеграционная проверка конкурентных запросов. Исходные варианты на pthread и epoll сохранены в `examples/` для изучения; рабочий сценарий использует `src/server.c`.

## Запуск в Linux

Нужны компилятор C11, POSIX threads и Python 3 для проверки.

```sh
make
make test
./build/server 5000
```

Сервер слушает только `127.0.0.1`. Порт 0 позволяет выбрать свободный порт, который программа печатает при старте. Windows-пользователи могут запускать проект в Ubuntu/WSL.

## Протокол

Каждая команда и каждый ответ заканчиваются переводом строки.

| Команда | Результат |
|---|---|
| `P a` | Положить один печатный ASCII-символ: `OK` или `FULL` |
| `C` | Извлечь первый символ: `OK a` или `EMPTY` |
| Некорректная команда | `ERR` |

Ёмкость очереди - 10 элементов, максимум 64 одновременных клиента; операции добавления и извлечения не ждут появления места или данных. Содержимое хранится в памяти и исчезает при остановке сервера. Сервис предназначен для локальной демонстрации сетевого обмена и синхронизации.

Проверка использует настоящий процесс сервера и TCP-соединения: разделённая команда, несколько команд в одном пакете, переполнение/FIFO, восемь параллельных производителей и некорректный ввод. Обработка лабораторных модулей ядра для этой демонстрации не требуется.
